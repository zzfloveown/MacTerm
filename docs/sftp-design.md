# SFTP 设计

SFTPCore 通过系统 OpenSSH 的 sftp 子系统收发 SFTP v3，目录与属性为结构化数据。旧版基础传输入口继续使用系统 sftp。独立文件标签保留各自的双栏路径和选中项。双栏支持导航、拖拽、递归复制、远端重命名和移动、权限修改、空目录删除及小型 UTF-8 文件编辑。文本写入会检查原内容及权限，并通过 OpenSSH 原子重命名扩展发布。

TransferCore 将任务写入 SQLite，最多三项并发。暂停与应用重启后可恢复。续传使用任务 UUID 指定临时文件，恢复前比较字节前缀，发布前再次比较全部内容和文件大小。下载通过同目录硬链接发布，上传通过 SFTP RENAME 发布。默认拒绝覆盖现有目标。取消保留临时文件，便于诊断。递归任务按文件入队，目录结构先创建，失败可能保留已创建目录。暂未实现覆盖选择、任务级临时文件清理和高延迟网络下的传输流水线。

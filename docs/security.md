# 安全

- 交互 SSH 由 OpenSSH 管理首次信任和指纹变更校验。非交互请求要求既有信任。
- 私钥引用不含私钥内容。Keychain 凭据按服务器 ID 隔离。每个主机默认采用手动认证；启用 Keychain 自动认证后，随包的独立 SSHAskPass 助手用权限为 0600 的一次性令牌定位主机，并最多提交一次密码。密码仅经标准输出管道交给 OpenSSH，不进入命令参数、环境变量或日志。主机密钥确认、私钥口令及其他交互挑战由原生 macOS 安全输入框逐次处理。
- 一次性令牌在进程退出时清理，并在助手读取时立即删除。助手以无符号链接打开令牌，校验所有者、文件类型和权限；旧配置解码时 Keychain 登录保持关闭。
- 移除服务器配置时，Keychain 凭据和该服务器的隧道、监控历史及告警规则会一并清除。
- 进程适配器直接传递 argv。远端命令参数逐一进行 POSIX shell 引用。SFTP 对命令语法敏感的路径字符采用拒绝策略。
- Kubernetes Secret 列表只显示名称与类型。使用受信任的 kubeconfig，kubectl 可能按该文件执行本地凭据插件。
- 公共源代码、Actions 日志和产物应排除企业地址与凭据。远端文件和容器删除要求确认。
- 后续审计覆盖依赖漏洞扫描、主机信任隔离、临时输出上限、SFTP 覆盖和权限、传输中断以及 Docker/Kubernetes 的授权边界。

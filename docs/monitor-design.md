# 监控设计

SSH 采集读取 Linux CPU、内存、磁盘、网络、负载、系统信息和温度。CPU 使用前八项计数差值。网络通过计数差值计算速度。磁盘扇区按 512 字节换算。内存使用量为总量减 MemAvailable。进程按 PID、用户和参数校验后可发送 SIGTERM，界面要求确认。

每主机共享一项采集任务，已建立的终端 SSH 主连接可以复用，其他情况下使用独立的 OpenSSH 控制套接字。状态跨窗口共享。历史数据保留 24 小时，支持 30 分钟、1 小时、24 小时查询和 CSV 导出。阈值规则和最近 500 条告警按主机持久化，并可授权 macOS 通知。连接失败告警基于采集请求错误，可能包含认证或采集命令问题。

# 测试

新增测试应覆盖正常入口、认证及主机信任错误、取消、重复操作、异常输入和旧数据迁移。编译、测试、打包均在 GitHub Actions 完成。当前单元测试覆盖服务器存储、连接安全参数、SFTP 路径边界及 Linux 采样计算。参见验收记录获取结果。

真机验收覆盖 macOS 14 ARM64、中文输入、窗口和分屏，Linux 环境验证 vim、htop、tmux、SFTP、监控、转发和容器管理，Kubernetes 使用专用非生产集群。

CI 的 SSH/SFTP 集成脚本在 ARM64 Runner 的回环地址启动独立 sshd，临时生成服务器和客户端密钥。测试覆盖 SSH 命令参数往返、错误指纹拒绝、中文目录和文件名、上传下载字节一致性、重命名与删除。

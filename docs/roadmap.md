# 路线图

| 阶段 | 已实现的范围 | 下一步 |
|---|---|---|
| P1 | SwiftPM、SwiftUI 工作区、GRDB 初始迁移、Keychain API、GitHub Actions | 补全数据库、设置和备份恢复 |
| P2 | OpenSSH PTY、交互认证、多标签、分屏、手动重连 | 验证 Linux PTY 与交互认证、SSH Config 导入、指纹管理、恢复、搜索和历史 |
| P3 | SFTP 双栏、基础文件操作和传输记录 | 结构化列表、属性、拖拽、递归、队列和校验续传 |
| P4 | Linux 基础指标、进程列表、内存告警 | 共享长连接、详细指标、历史、CSV、进程操作、通知和其余阈值 |
| P5 | ProxyJump 和三类转发参数 | 建立状态回报、冲突与多级转发验收、自动重连 |
| P6 | Docker 和 nerdctl CLI 探测、基础查询和容器操作。kubectl 查询和 Secret 脱敏 | 镜像写操作、容器和 Pod 终端、扩缩容、实际集群验收 |
| P7 | 云端 ARM64 DMG、App ZIP、签名公证工作流初版 | 审计、性能、App 启动和安装测试、凭据配置、内网分发 |

# 路线图

| 阶段 | 当前范围 | 后续验收与缺口 |
|---|---|---|
| P1 | SwiftPM、SwiftUI、GRDB、Keychain、服务器分组与配置备份；备份含隧道配置并兼容旧版文件 | 多窗口配置一致性 |
| P2 | 多标签和分屏（支持指定副分屏标签）、SSH Config 导入、指纹查询、密钥生成、搜索、标签恢复、快捷命令与命令历史、光标与缓冲区设置、可选自动重连、按主机显式启用的 Keychain 密码提交与原生 askpass 提示 | macOS 14 真机交互测试 |
| P3 | 独立文件标签、本地与远端结构化属性列表、文件名筛选、拖拽、递归、文本编辑、持久化队列、校验续传、二次确认覆盖同名文件、已完成记录与任务级 `.part` 临时文件清理 | 暂停实测及 WAN 流水线性能 |
| P4 | 共享采集、Linux 系统信息、自动加载进程管理、磁盘分区进度条与网络统计、历史、CSV 和通知告警；CPU 现区分用户态、系统态、空闲和 I/O Wait | 跨发行版及通知真机验收 |
| P5 | ProxyJump、三类转发、就绪检查、错误提示和重试；隧道配置按主机写入 GRDB、支持备份与多条并行运行 | 不同 sshd 转发策略及应用重启后的实机体验 |
| P6 | Docker/nerdctl 查询和快捷点选操作、容器终端 Shell 选择、kubectl 资源快捷点选及 Pod 终端、Deployment 扩缩容 | 验证 macOS 界面到容器环境的端到端操作 |
| P7 | ARM64 DMG、App ZIP、原生多尺寸 ICNS、云端挂载启动和签名校验 | Developer ID 凭据、公证、macOS 14 终端和界面实机验收、受控内网 HTTPS 分发 |

继续完善真机交互与生产环境验收；AppIcon.icns、工作台搜索/分组筛选与快捷入口、服务器详情、命令历史、SFTP 覆盖确认与临时文件清理及本地配置级联清理已实现。优先完成 macOS 14 GUI 与真实集群联动验收。正式发布需要仓库签名公证 Secrets 和企业分发端点。
